API قیمت طلا — داده‌های لحظه‌ای بازار طلا

با API قیمت طلا، به داده‌های لحظه‌ای طلا، سکه و ارز دسترسی پیدا کنید. این سرویس هر ۵ دقیقه به‌روزرسانی می‌شود و برای اپلیکیشن‌ها، سایت‌های خبری و پلتفرم‌های مالی ایده‌آل است.

داده‌های موجود

  • قیمت لحظه‌ای طلا ۱۸ عیار
  • سکه بهار آزادی، امامی، نیم سکه و ربع سکه
  • اونس جهانی طلا
  • درصد تغییرات نسبت به روز قبل

مخاطبان این سرویس

مخاطبکاربرد
سایت‌های خبری اقتصادینمایش تیکر لحظه‌ای طلا و سکه
اپلیکیشن‌های مالیریالرت و نوتیفیکیشن قیمت
طلافروشانبه‌روزرسانی قیمت ویترین فروشگاه
تحلیلگرانجمع‌آوری داده برای تحلیل فنی
مستندات فنی کامل شامل پارامترها و نمونه کد در بخش «مستندات فنی API» در دسترس است.
