API قیمت امروز آهن — جامع‌ترین پایگاه داده قیمت آهن‌الات

با اشتراک API قیمت آهن، به بانک اطلاعاتی کامل و به‌روز از بیش از ۹۰ نوع مقطع فولادی در بازار ایران دسترسی پیدا می‌کنید. از تیرآهن و میلگرد گرفته تا ورق، لوله، پروفیل و تمامی محصولات فلزی — همه در یک API واحد، با ساختار JSON استاندارد و پاسخ سریع.

🏗️ پشتیبانی از تمام محصولات فلزی

این API طیف گسترده‌ای از محصولات مرتبط با آهن و فولاد را پوشش می‌دهد و نیازی به خرید اشتراک جداگانه برای هر دسته نیست. با یک کلید API، به تمامی محصولات زیر دسترسی خواهید داشت:

  • تیرآهن: تیرآهن معمولی، تیرآهن هاش، تیرآهن لانه زنبوری
  • میلگرد: میلگرد آجدار، میلگرد ساده، میلگرد ST37، میلگرد استیل، میلگرد بستر، میلگرد حرارتی
  • ورق فولادی: ورق گالوانیزه، ورق رنگی، ورق روغنی، ورق آلومینیوم، ورق مسی، ورق استیل، ورق سربی
  • لوله و پروفیل: لوله مانیسمان، لوله گالوانیزه، لوله داربست، لوله استیل، پروفیل ساختمانی و صنعتی
  • محصولات تخصصی: نبشی، ناودانی، سپری، ریل (قطار، آسانسور، معدنی، جرثقیلی)، تسمه، شفت و...
  • اتصالات و متفرقه: زانو، سه راهی، تبدیل، بوشن، فلنج، پیچ و مهره، گریتینگ، مش و...
💡 با یک اشتراک واحد، به تمام این دسته‌ها دسترسی دارید. لیست کامل شناسه‌های محصولات در بخش مستندات فنی موجود است.

📅 تاریخ دقیق قیمت — همیشه می‌دانید داده‌ها متعلق به چه روزی هستند

یکی از مهم‌ترین ویژگی‌های این API، شفافیت کامل در تاریخ داده‌هاست. در پاسخ هر درخواست، فیلد تاریخ آخرین قیمت به صورت تاریخ شمسی دقیق (مثال: 1405-05-10) همراه هر محصول ارسال می‌شود.

  • تاریخ به‌روزرسانی هر سایز به صورت مجزا ثبت می‌شود.
  • می‌توانید به راحتی بررسی کنید که قیمت یک محصول مربوط به امروز است یا روزهای قبل.
  • مناسب برای سیستم‌های حساس مالی که نیاز به اعتبارسنجی زمانی داده دارند.

📈 نوسان و تغییر قیمت ۲۴ ساعته

برای هر سایز از محصول، فیلد 24h میزان تغییر قیمت در ۲۴ ساعت گذشته را نشان می‌دهد. این قابلیت به شما کمک می‌کند تا:

  • روند صعودی یا نزولی بازار را لحظه‌ای رصد کنید.
  • هشدارهای قیمتی (Price Alert) در اپلیکیشن خود بسازید.
  • نمودارهای نوسان قیمت را برای کاربران نهایی نمایش دهید.
  • تصمیم‌گیری خرید و فروش را بر اساس داده‌های واقعی انجام دهید.

🔄 به‌روزرسانی در روزهای کاری

قیمت‌ها در تمام روزهای کاری هفته (شنبه تا چهارشنبه) به صورت خودکار و از معتبرترین منابع بازار آهن جمع‌آوری و به‌روزرسانی می‌شوند.

  • داده‌های روزهای تعطیل (پنج‌شنبه و جمعه) مطابق آخرین قیمت روز کاری قبل باقی می‌مانند.
  • تاریخ دقیق در پاسخ API نشان می‌دهد که داده‌ها متعلق به چه روزی هستند.

🎁 بخش رایگان — بدون نیاز به خرید اشتراک

برای اینکه بتوانید قبل از خرید، کیفیت و ساختار داده‌ها را بررسی کنید، بخش قابل‌توجهی از محصولات به صورت کاملاً رایگان در دسترس قرار گرفته‌اند. برای استفاده از این دسته‌ها حتی نیازی به ارسال پارامتر auth (کلید API) هم ندارید.

برخی از محصولات رایگان عبارتند از:

  • بست داربست، فلنج گلودار، کپ، گل میخ عرشه فولادی
  • گریتینگ، لوله گوشتدار، لوله استیل، لوله استیل صنایع غذایی
  • مش، میلگرد بستر، میلگرد حرارتی، نبشی
  • پروفیل کنگره، پروفیل استیل، پروفیل زد
  • ریل آسانسوری، ریل جرثقیلی، ریل معدنی
  • ورق آلوزینک، ورق گالوالوم، ورق کرکره، ورق سربی، ورق استیل
  • و بیش از ۳۰ دسته دیگر...
🚀 همین الان می‌توانید بدون ثبت‌نام و بدون پرداخت، API رایگان را تست کنید. لیست کامل محصولات رایگان در مستندات فنی موجود است.

⚖️ سیاست استفاده منصفانه (Fair Use Policy)

برای حفظ کیفیت سرویس و پایداری سرورها برای تمامی کاربران، خواهشمندیم در استفاده از API اصول منصفانه را رعایت فرمایید:

  • Cache کردن پاسخ‌ها: با توجه به به‌روزرسانی روزانه قیمت‌ها، توصیه می‌شود پاسخ‌ها را حداقل برای ۱ ساعت در سمت خود کش کنید.
  • عدم ارسال درخواست‌های تکراری: از ارسال چندین درخواست همزمان برای یک دسته خودداری کنید.
  • استفاده در بازه منطقی: حداکثر چند درخواست در دقیقه برای هر کلید API کافی است.
  • عدم اشتراک‌گذاری کلید: کلید API اختصاصی شماست و نباید در اختیار دیگران قرار گیرد.

در صورت مشاهده استفاده نادرست یا فشار غیرمنصفانه بر سرور، ممکن است دسترسی موقتاً محدود شود. با رعایت این موارد، به پایداری سرویس برای همه کمک می‌کنید. 🤝
