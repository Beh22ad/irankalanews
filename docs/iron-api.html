مستندات فنی API قیمت آهن

با استفاده از این سرویس، می‌توانید به صورت لحظه‌ای و برنامه‌نویسی‌شده، آخرین قیمت انواع سایزها و مشخصات مختلف مقاطع فولادی، لوله، ورق و سایر آهن‌آلات را دریافت کنید.

💡 نکته مهم: با هر بار فراخوانی این API برای یک دسته‌بندی خاص، شما لیست کامل تمامی سایزهای موجود در آن دسته را به همراه جزئیات قیمت هر سایز به صورت یکجا دریافت خواهید کرد و نیازی به درخواست جداگانه برای هر سایز نیست.

آدرس درخواست (Endpoint)

GET https://irankalanews.ir/ahan/?id=PRODUCT_ID&auth=YOUR_API_KEY
⚠️ نکته امنیتی: ارسال هدر User-Agent معتبر در درخواست‌های شما الزامی است. درخواست‌های فاقد User-Agent به صورت خودکار مسدود می‌شوند.

پارامترهای درخواست

نام پارامتر نوع الزامی توضیحات
id string بله شناسه دسته‌بندی محصول (مثال: looleh-steel). لیست کامل در پایین صفحه موجود است.
auth string خیر* کلید API اختصاصی شما.
رایگان برای دسته‌های رایگان الزامی نیست، اما برای داده‌های پریمیوم الزامی است.

ساختار پاسخ (Response)

در صورت موفقیت‌آمیز بودن درخواست، سرور یک شیء JSON باز می‌گرداند که آرایه data آن شامل لیست تمام سایزهای محصول به همراه اطلاعات زیر است:

فیلد (داخل آرایه data) نوع توضیحات دقیق
id string شناسه منحصر‌به‌فرد هر سایز (مثال: looleh-steel_3734413042). برای شناسایی دقیق همان سایز در سیستم خود از این مقدار استفاده کنید.
نام string نام دقیق محصول به همراه سایز، رده و مشخصات فنی (مثال: لوله استنلس استیل صنعتی 316 2 اینچ رده 40)
قیمت string آخرین قیمت ثبت شده برای آن سایز خاص (به تومان)
تاریخ آخرین قیمت string تاریخ شمسی دقیق بروزرسانی قیمت (مثال: 1403-05-10)
24h string میزان تغییر قیمت در ۲۴ ساعت گذشته (نشان‌دهنده نوسان اخیر بازار برای آن سایز خاص)
💡 نکته کلیدی درباره شناسه (ID) سایزها: همان‌طور که در نمونه JSON زیر مشاهده می‌کنید، هر ردیف (سایز خاص) دارای یک فیلد id منحصر‌به‌فرد است. شما می‌توانید در کد نویسی خود، آرایه دریافتی را پیمایش کرده و با چک کردن این id، قیمت و مشخصات دقیق همان سایز خاص را استخراج و در دیتابیس یا سیستم خود مدیریت کنید.

نمونه کد درخواست

در این مثال‌ها، نحوه دریافت لیست سایزها و استخراج اطلاعات یک سایز خاص با استفاده از id منحصر‌به‌فرد آن نشان داده شده است. 

<?php
$productId = 'looleh-steel';
$apiKey    = 'YOUR_API_KEY_HERE';

$url = "https://irankalanews.ir/ahan/?id={$productId}&auth={$apiKey}";

$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, $url);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_USERAGENT, 'MyApp/1.0');

$response = curl_exec($ch);

if (curl_errno($ch)) {
    die('cURL Error: ' . curl_error($ch));
}

curl_close($ch);

$data = json_decode($response, true);

if (json_last_error() !== JSON_ERROR_NONE) {
    die('Invalid JSON: ' . json_last_error_msg());
}

if (!isset($data['status']) || $data['status'] !== 'ok') {
    die('API Error: ' . ($data['message'] ?? 'Unknown error'));
}

$targetId = 'looleh-steel_3734413042';
$foundItem = null;

foreach ($data['data'] as $item) {
    if (($item['id'] ?? '') === $targetId) {
        $foundItem = $item;
        break;
    }
}

if ($foundItem === null) {
    die('سایز مورد نظر یافت نشد.');
}

echo "سایز: " . ($foundItem['نام'] ?? '-') . PHP_EOL;
echo "قیمت: " . ($foundItem['قیمت'] ?? '-') . " تومان" . PHP_EOL;
echo "تغییر ۲۴ ساعته: " . ($foundItem['24h'] ?? '-') . PHP_EOL;
echo "تاریخ بروزرسانی: " . ($foundItem['تاریخ اخرین قیمت'] ?? '-') . PHP_EOL;
?>
const productId = 'looleh-steel';
const apiKey = 'YOUR_API_KEY_HERE';

const url = `https://irankalanews.ir/ahan/?id=${productId}&auth=${apiKey}`;

async function main() {
    try {
        const response = await fetch(url, {
            headers: {
                'User-Agent': 'MyApp/1.0'
            }
        });

        const data = await response.json();

        if (data.status !== 'ok') {
            throw new Error(data.message || 'Unknown error');
        }

        const targetId = 'looleh-steel_3734413042';
        const item = data.data.find(x => x.id === targetId);

        if (!item) {
            console.log('سایز مورد نظر یافت نشد.');
            return;
        }

        console.log('سایز:', item['نام']);
        console.log('قیمت:', item['قیمت'], 'تومان');
        console.log('تغییر ۲۴ ساعته:', item['24h']);
        console.log('تاریخ بروزرسانی:', item['تاریخ اخرین قیمت']);

    } catch (err) {
        console.error(err.message);
    }
}

main();

کدهای خطا و وضعیت‌ها

وضعیت (status) حساب (account) توضیحات
ok paid / free درخواست موفقیت‌آمیز بود و داده‌ها (شامل لیست سایزها و قیمت‌ها) در آرایه data قرار دارند.
failed unauthorized کلید API نامعتبر است یا ارسال نشده، در حالی که محصول درخواستی پولی است.
failed expired اشتراک شما منقضی شده است و دسترسی به داده‌های پولی قطع شده است.
failed blocked آدرس IP شما به دلیل نقض قوانین یا درخواست‌های مشکوک مسدود شده است.
failed — شناسه محصول (id) اشتباه است یا فایل داده‌ای برای آن یافت نشد.
